# แบบฝึกหัดข้อสอบ ป.5 (P5 Practice Quiz)

เว็บแบบฝึกหัดเตรียมสอบ ป.5 เน้น **เศษส่วน ทศนิยม และการนำเสนอข้อมูล** พร้อมวิชาภาษาอังกฤษ ภาษาไทย สังคมศึกษา และวิทยาศาสตร์

- ทำข้อสอบบนโทรศัพท์หรือคอมพิวเตอร์
- ตรวจคะแนนและดูเฉลยอธิบายเหตุผล
- ชุดฝึกแยกบทและชุดสอบจำลองจับเวลา
- เก็บประวัติคะแนนในเบราว์เซอร์ของผู้ใช้ผ่าน `localStorage` โดยไม่มีระบบบัญชีผู้ใช้
- ใช้ไฟล์ HTML แบบ Static ไม่ต้องมี Backend

## ข้อชี้แจงสำคัญ / Unofficial disclaimer

> **หมายเหตุ: เว็บไซต์ฝึกทบทวนเพื่อการศึกษา (Unofficial Practice Exam)**
>
> เว็บไซต์นี้จัดทำขึ้นโดยอิสระ เพื่อให้นักเรียนระดับชั้นประถมศึกษาปีที่ 5 ฝึกทบทวนความรู้และเตรียมตัวสอบ
>
> เนื้อหาและแนวข้อสอบจัดทำขึ้นโดยอ้างอิงกรอบหัวข้อการเรียนรู้ที่โรงเรียนแจ้งให้ผู้ปกครองทราบ และปรับเป็นแบบฝึกหัดที่มีเนื้อหาใกล้เคียงกับระดับชั้น ป.5
>
> **เว็บไซต์นี้ไม่ใช่เว็บไซต์ทางการของโรงเรียนหรือผู้จัดการสอบ ไม่ได้มีส่วนเกี่ยวข้องหรือได้รับการรับรองจากหน่วยงานดังกล่าว และข้อสอบทั้งหมดไม่ใช่ข้อสอบจริงหรือข้อสอบที่ได้รับจากผู้จัดการสอบ**
>
> เนื้อหาและเฉลยอาจมีข้อผิดพลาดหรือไม่ครอบคลุมแนวข้อสอบจริงทั้งหมด โปรดใช้ประกอบการฝึกทบทวนและตรวจสอบกับครูผู้สอนหรือแหล่งเรียนรู้ที่เชื่อถือได้

**ชื่อการสอบที่ปรากฏเป็นเพียงการอ้างอิงบริบทเพื่อช่วยระบุหัวข้อที่ต้องการฝึก ไม่ใช่การแสดงความเป็นพันธมิตรหรือผู้แทนของผู้จัดการสอบ**

## เปิดใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ (Chrome / Edge / Safari) ได้ทันที หรือใช้งานผ่าน GitHub Pages

## เผยแพร่บน GitHub Pages

1. สร้าง Repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง root ของ Repository
2. เปิด **Settings → Pages**
3. ที่ **Build and deployment → Source** เลือก **Deploy from a branch**
4. เลือก Branch `main` และ Folder `/(root)` จากนั้นกด **Save**
5. เข้าเว็บตาม URL ที่ GitHub Pages แสดง (โดยทั่วไปมีรูปแบบ `https://<username>.github.io/<repo>/`)

> เว็บเป็น static site ทั้งหมด ไม่จำเป็นต้องใช้ Database หรือ API สำหรับการทำข้อสอบ
